# Quickstart: FEAT-07 Subtasks (Checklist)

## Step-by-Step Verification on Device (Samsung Galaxy A71)

### 1. Open Task Detail
- Open any existing task from the tasks screen.
- Scroll to the "Alt Görevler" section.

### 2. Add New Subtask
- Type "Tasarım incelemesi yap" into the quick-add input at the bottom of the section.
- Tap the "+" or send button.
- Verify the new subtask appears in the list and the total count updates (e.g. "0/1 tamamlandı").

### 3. Toggle Subtask Completion
- Tap the checkbox next to the subtask.
- Verify it is checked, line-through text is displayed, and progress updates to "1/1 tamamlandı • %100".
- Tap again to verify it unchecks cleanly.

### 4. Delete Subtask (Owner Only)
- Tap the delete icon (trash) next to the subtask.
- Confirm deletion in the dialog.
- Verify the subtask is removed from the list.
